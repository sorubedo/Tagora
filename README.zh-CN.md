# Tagora

一个告诉你「现在该做什么」的智能任务看板。

[English](README.md)

定义好日常作息、每周安排或特定日期计划，Tagora 会根据时间自动激活对应标签，再通过简单的 AND/OR/NOT 逻辑判断出当前应该关注哪些任务。

## 怎么用

1. **创建标签**（比如「工作」「在家」「运动」）
2. **设置时间段** — 每日重复（09:00–12:00）、每周重复（周一~周五）、日期范围、或截止日
3. **定义任务**，条件像这样：*"工作" 且 "上午" 但排除 "会议"*
4. 引擎自动运转 — 控制面板随时告诉你当前激活了什么

## 功能

- **标签自动激活** — 根据时间表自动开关标签
- **六分类看板** — 激活中、截止日、每日、明日、每周、未激活
- **24 小时时间线** — 彩色时间块直观展示一天的安排
- **布尔条件任务** — 在标签上组合 AND/OR/NOT 逻辑树
- **WebDAV 备份** — 自动轮换，保留最近 10 份
- **后台服务** — 持续检测标签状态并推送任务通知
- **两套预设** — 通用作息 / 学生学期课表，一键切换

## 开始使用

```bash
./gradlew assembleDebug
./gradlew installDebug
```

需要 Android 8.0+ (API 26)。
